# 🛒 FASCO Online Shopping Website

Сучасний та інтерактивний інтернет-магазин, розроблений на React з упором на ефектний візуал, плавні анімації та кастомну стилізацію.

---

## 🎨 Дизайн та Макет
Проєкт реалізовано на основі безкоштовного макету з Figma Community:
👉 **[Посилання на Figma макет: Online Shopping Website](https://www.figma.com/community/file/1277998375898787881/online-shopping-website-design-ecommerce-store-website-ui-kit)**


👉 **[Посилання на сайт](https://vladkugot.github.io/fascoShop/)**
---

## 🛠️ Стек технологій
* **Frontend:** React (TypeScript)
* **Збірка:** Vite
* **Стилі:** SCSS (Sass) / CSS Modules
* **Анімації:** Framer Motion *(якщо плануєш додавати)*

---

## 🚀 Функціонал та Вау-ефекти
* [ ] Адаптивна верстка під мобільні пристрої та планшети.
* [ ] Ефектні Hover-анімації карток товарів.
* [ ] Інтерактивний кошик покупок.
* [ ] Плавний скрол та поява елементів при завантажені.
